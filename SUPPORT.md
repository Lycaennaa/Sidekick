# Support

Use this repository’s GitHub Issues for bug reports, questions, and feature requests.

Before filing an issue, check [Setup](SETUP.md), [Features](FEATURES.md), and existing issues. Include the Sidekick version, macOS version, steps to reproduce, and expected versus actual behavior.

Issues are public. Do not include OAuth tokens, clipboard contents, private screenshots, personal data, or signing material. Redact logs before attaching them.
