# Development

## Requirements

- macOS 15 or later with Xcode 16.4 or later.
- Just, XcodeGen, and SwiftLint. Install Just with `brew install just`; `just setup` installs missing XcodeGen and SwiftLint packages using Homebrew.
- Network access for Swift Package Manager and the build-time ClearURLs rules fetch.

## Build and test

From the repository root:

```sh
just setup
just generate-project
just build
just test
just lint
just check
```

Run `just install-hooks` to enable a local pre-commit check for staged Xcode project metadata.

`just test-permissions` runs a separate hosted integration check in an inert test host, using macOS's live Screen Recording and notification authorization status APIs. It only reads current status and does not request either permission.

`just ci` runs the local required checks plus a Release build. `just package` creates an ad-hoc-signed ZIP and DMG. Neither artifact is Developer ID signed or notarized.

## Generated project and rule data

`project.yml` is the XcodeGen source of truth. `just generate-project` fetches the ClearURLs rules if no build snapshot exists, then generates the Xcode project. `just refresh-clearurls` fetches the current `master` file again and regenerates the project. The fetched file is cached under ignored build output and its SHA-256 is printed; the upstream branch is mutable, so separate builds can contain different rules.

`Sidekick.xcodeproj` is generated and ignored except for the checked-in `project.xcworkspace/xcshareddata/swiftpm/Package.resolved` lockfile. CI and release workflows regenerate project data before building. Run `just generate-project` before opening or building locally.

The packaged app processes URLs locally using its bundled rules. It does not fetch rules at runtime. Tests exercise the default controller with a real named `NSPasteboard` and the rules resource generated by the build.

## Twitch OAuth

The Twitch Notifications panel can save a client ID in UserDefaults. A saved ID takes precedence over the build-time `TwitchOAuthClientID` app Info.plist value. The build-time value is `none` in `project.yml`; change it when producing a build that should include a default ID. No Git hooks or release workflow inject or rewrite client IDs.

## Xcode project maintenance

Edit `project.yml`, then regenerate with `just generate-project`. Do not hand-edit the generated project file. Keep SwiftLint configuration in `.swiftlint.yml` and run `just lint` after Swift changes.

SwiftLint is blocking in local and GitHub checks. `just lint-fix` applies its available automatic corrections; review the resulting diff and fix remaining findings manually, then rerun `just lint`.

Routine `just test` skips the live GitHub downloader check. Run `just test-equicord-release-network` to exercise the default URLSession path against the latest release.
