# Sidekick

Sidekick is a macOS menu bar utility for clipboard activity, screenshots, audio status, output volume, and optional Twitch notifications. Requires macOS 15 or later.

## Quick start

Download the ZIP or DMG from this repository’s GitHub Releases. Verify the asset’s SHA-256 digest shown by GitHub before opening it. Releases are ad-hoc signed, not Developer ID signed or notarized; see [SETUP.md](SETUP.md) for installation and Gatekeeper notes.
